# SKS Windows

A lightweight Windows 10 optimization project focused on gaming, performance, and low-resource PCs.

## About

SKS Windows is an open-source project focused on optimizing Windows 10 for older and low-resource computers while maintaining stability, usability, and compatibility.

The project aims to provide controlled and reversible system optimizations rather than removing essential Windows components.

## Goals

- Improve system performance.
- Reduce unnecessary resource usage.
- Optimize Windows for gaming.
- Support low-resource PCs.
- Maintain system stability.
- Make optimizations reversible.
- Provide transparent and documented changes.

## Project Status

Early development

## Vision

SKS Windows is also an experimental project that will help develop knowledge and technologies that may contribute to the long-term development of SKS OS.
